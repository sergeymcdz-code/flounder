## Желательные

1. `Protocol.tsx:68,165` — `tabIndex={0}` на таблицах действует на всех ширинах, а прокрутка есть только ≤480 px (`Public.module.css:526`). На десктопе каждая таблица протокола становится лишней Tab-остановкой без действия. Вариант: вешать `tabIndex` только при `matchMedia('(max-width: 480px)')` или обернуть таблицу в прокручиваемый `div` с `tabIndex` и `aria-label`.
2. `MyRegistrationsPage.module.css:263-266` — `.hintCancelled` остался в danger-палитре (бордер/фон/текст красные), тогда как `.statusCancelled` (`:150-153`) переведён в нейтральный muted. Отмена пользователем — не нарушение; по ADR п.1 красный только опасность/DSQ/LIVE. Развести `.hintCancelled` с `.hintRejected` на muted.
3. `MyRegistrationsPage.module.css:41-49` и `:271` — `.emptyState` объявлен дважды (второй блок переопределяет border/background первого). Слить в одно правило.
4. `index.html` — `<meta name="theme-color">` остаётся статичным `#182126` для светлой темы публичных страниц (цвет адресной строки на телефоне тёмный при светлой странице). Можно добавить второй `meta` с `media="(prefers-color-scheme: light)"` или менять из `ThemeProvider`.
5. `JudgePanelPage.tsx:185` — `scrollIntoView` на фокусе срабатывает и на десктопе; с `block:'nearest'` это безвредно, но при Tab по строкам у нижнего края страница будет подпрыгивать. Если будут жалобы — ограничить `inline`-прокруткой контейнера `.tableWrap` вручную.
6. Документы датированы «14.10.2026» при PR от 13.10 — поправить дату при следующем касании.
