2. После деплоя: `select version, success from flyway_schema_history order by installed_rank desc limit 3` — V051 success; `\d users` — индекс `ux_users_email_lower`, колонка `tokens_valid_after`; все email в нижнем регистре.
3. Вход существующим аккаунтом в другом регистре (`ADMIN@…`) работает; повторная регистрация адреса в другом регистре → 409 с нейтральным текстом (после Б1 — и в UI).
4. Два окна одного пользователя → «Выйти везде» в одном → второе получает 401 при следующем запросе; админская блокировка → участник выбывает сразу, после разблокировки нужен новый вход.
5. Пять неверных паролей с одного устройства → 429 «Повторите через N минут» только с этого устройства; с телефона (другой IP, мобильная сеть) верный пароль проходит.
6. `https://sportgate.pro/swagger-ui/index.html` и `/v3/api-docs` — SPA/404, не Swagger; `/actuator/health` — UP.
7. `infra/.env.prod`: `JWT_SECRET` — Base64 (`echo -n "$JWT_SECRET" | base64 -d | wc -c` ≥ 32); после Б2 — выставить `APP_AUTH_REGISTRATION_MAX_PER_IP` с запасом на день соревнований (например 100) и вернуть 20 после.
