Пустой набор организаций — Hibernate 6 корректно рендерит пустой `IN`; покрыто косвенно (judge с одной организацией → `$[0].id`).

- `EventAccessService` без `SecurityContextHolder`: реальный principal из JWT — `PlatformUserPrincipal` с authorities, admin распознаётся. `AuthenticatedUserPrincipal.getAuthorities()` по умолчанию пустой — лямбда-принципалы в старых тестах заменены на `PlatformUserPrincipal` (`EventIntegrationTest.platformAdminAuthentication`). `@BeforeEach useAdminPrincipalWithAuthorities` в `EventIntegrationTest`/`CompetitionIntegrationTest` подменяет принципал `@WithMockUser` на `PlatformUserPrincipal` — тестовый костыль, но корректный; при желании позже заменить `@WithMockUser` на собственный `@WithPlatformUser`.
