# Демо-набор данных «M» (Flounder, T10 п.1)

Сгенерировано скриптом `scripts/demo/generate_set_m.py` (Python 3, openpyxl), seed = 2026. Все ФИО вымышленные, совпадения случайны.

## Файлы

| Файл | Содержимое |
|---|---|
| `set-M.xlsx` | 200 заявок в формате шаблона импорта (ТЗ §5.4), лист «Заявки» |
| `set-M-with-errors.xlsx` | те же 200 строк + 3 ошибочные строки в конце (строки 202–204 файла): неверная дата `31.02.2013`, неизвестный код `X-999`, пустая фамилия |
| `set-M.json` | `athletes[]` (120 спортсменов) и `entries[]` (200 заявок, ссылка `athleteId`) |
| `README.md` | этот файл |

## Формат Excel

Первая строка — заголовки, строго по ТЗ §5.4:

```
Фамилия | Имя | Отчество | Дата рождения (ДД.ММ.ГГГГ) | Пол (М/Ж) | Клуб/Город | Дисциплина (код) | Заявочное время (мм:сс.сс или пусто)
```

Одна строка = одна заявка. Дата — `ДД.ММ.ГГГГ`, пол — `М`/`Ж`, время — `мм:сс.сс` или пусто (NT). Коды дисциплин: `M-50-FREE`, `F-50-FREE`, `M-100-FREE`, `F-100-FREE` (мальчики только `M-`, девочки только `F-`).

## Параметры генерации

- Спортсменов: 120 (М: 60, Ж: 60); из них 80 заявлены на оба вида (50 и 100 в/с), 40 — на один.
- Годы рождения 2010–2015, равномерно (20 спортсменов на год). Дата рождения — случайный день года; у одного спортсмена дата одинакова во всех строках.
- Клубы (8): СШОР №1, Дельфин, Волна, Нептун, Акватика, Старт, Чайка, Орбита; города не используются.
- Заявочное время: нормальное распределение вокруг средних по году рождения (50 в/с: 2015 г.р. ≈ 50 с … 2010 г.р. ≈ 34 с, σ ≈ 2.2 с; 100 в/с ≈ ×2.3; девочки ≈ +5 %), обрезка 50 в/с: 30–56.0 с, 100 в/с: 01:10.00–02:08.00.
- Без времени (NT): 20 заявок (10%).

## Проверка

Скрипт после генерации перечитывает `set-M.xlsx` и проверяет: заголовки символ в символ, 200 строк, 120 уникальных спортсменов (ФИО + дата), согласованность пола и кода дисциплины, корректность дат, разбор всех времён и их попадание в диапазон, ровно 20 NT. В `set-M-with-errors.xlsx` проверяется наличие трёх ошибочных строк в конце.

## Ожидаемый результат импорта

- `set-M.xlsx`: `total: 200, created: 200, errors: []`, `createdProfiles: 120`.
- `set-M-with-errors.xlsx`: `total: 203`, 3 ошибки — строки 202 (Дата рождения), 203 (Дисциплина (код)), 204 (Фамилия); остальные 200 импортируются.
