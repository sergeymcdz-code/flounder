# M03: примеры серверных PDF

[start-list.pdf](start-list.pdf) и [results.pdf](results.pdf) получены тем же `PdfRenderer`, который обслуживает API, на 200 заявках из `docs/scripts/demo/out/set-M.json`.

Это фикстура печати, а не результаты реального соревнования: заплывы разбиты по восемь дорожек, расписание и результаты заданы в тесте. Итоговый пример содержит ничью 1,1,3, DNS/DNF/DSQ и CORRECTED; один участник отмечен как снятый. Время генерации в шапке фиксировано для воспроизводимости примеров. Ранжирование production-кода не изменено.

После ревью 1 стартовый образец содержит 10 страниц, итоговый — 13. На страницах без вводной шапки вида помещаются три целых заплыва по восемь дорожек; перенос длинных имён и большая вводная часть могут уменьшать это количество. У строк VALID колонка «Статус» пуста.

Визуально проверены первые страницы обоих документов, страница стартового с тремя заплывами и последняя страница итогового: кириллица, переносы, повторение шапки и колонок таблицы, колонтитулы и отсутствие обрезания. Автотест проверяет формат A4, встроенность шрифтов и шапку на каждой странице.

Порядок видов в публичном PDF совпадает с публичным API: порядок сессии, порядок вида (null в конце), createdAt, id. В организаторском PDF нумерация учитывает все виды, включая DRAFT; поэтому до публикации номера могут отличаться от публичного протокола.

Перегенерация из `sport-platform/`:

```bash
mvn -q test -Dtest=PdfRendererTest -Ddocuments.writeSamples=true -Ddocuments.sampleDir=../docs/qa/M03-samples
```

Шрифт Noto Sans Regular/Bold хранится в `sport-platform/src/main/resources/fonts/`, лицензия SIL Open Font License 1.1 приложена там же. Рендерер не загружает ресурсы из сети.
