# M03: примеры серверных PDF

[start-list.pdf](start-list.pdf) и [results.pdf](results.pdf) получены тем же `PdfRenderer`, который обслуживает API, на 200 заявках из `docs/scripts/demo/out/set-M.json`.

Это фикстура печати, а не результаты реального соревнования: заплывы разбиты по восемь дорожек, расписание и результаты заданы в тесте. Итоговый пример содержит ничью 1,1,3, DNS/DNF/DSQ и CORRECTED; один участник отмечен как снятый. Время генерации в шапке фиксировано для воспроизводимости примеров. Ранжирование production-кода не изменено.

Визуально проверены первые страницы обоих документов и последняя страница итогового: кириллица, переносы, повторение шапки и колонок таблицы, колонтитулы и отсутствие обрезания. Автотест проверяет формат A4, встроенность шрифтов и шапку на каждой странице.

Перегенерация из `sport-platform/`:

```bash
mvn -q test -Dtest=PdfRendererTest -Ddocuments.writeSamples=true -Ddocuments.sampleDir=target/m03-samples
```

Шрифт Noto Sans Regular/Bold хранится в `sport-platform/src/main/resources/fonts/`, лицензия SIL Open Font License 1.1 приложена там же. Рендерер не загружает ресурсы из сети.
