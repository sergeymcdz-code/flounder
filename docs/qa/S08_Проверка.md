## SQL и время ответа

Проверка DataSource считает все подготовленные JDBC statements, включая запросы вне Hibernate: **один SQL на календарь из 50 карточек**. Запрос возвращает окно `count(*) over()`, страницу, total и города; пустая страница сохраняет total. Организация и площадка соединены в read-модели; дополнительные запросы на карточку отсутствуют.

Локальный замер настоящего API: 50 событий, 32 разных ключа кеша, у всех ответов `X-Flounder-Cached: false`. p95 **24,49 мс**, максимум **53,35 мс**, медиана **7,57 мс**. Это последовательный локальный замер, а не нагрузочная проверка production или 1000 одновременных зрителей.

- axe WCAG 2 A/AA + 2.1 AA: **0 нарушений во всех восьми сочетаниях**.
