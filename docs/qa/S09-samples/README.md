# S09: примеры серверных PDF

Файлы получены из `PrintFormsIntegrationTest` на изолированной PostgreSQL-фикстуре. Все имена и результаты тестовые. Фон грамоты создан тестом, логотип взят из существующих ресурсов SportGate.

- `heat-card-a5.pdf`: три опубликованных заплыва, по карточке на странице A5; снятый участник сохраняет дорожку.
- `heat-cards-a4x2.pdf`: те же три карточки на двух страницах A4, линия разреза посередине листа.
- `awards.pdf`: абсолют, две первые позиции при ничьей; четвёртое место и черновой заплыв исключены.
- `diploma.pdf`: пробная грамота Ивановой Марии, изменённый текст шаблона, фон и логотип.
- `start-list-bibs.pdf`, `results-bibs.pdf`: существующие протоколы M03 с назначенным номером 7.

Воспроизведение из `sport-platform/` при доступном Docker:

```sh
mvn -q test -Dtest=PrintFormsIntegrationTest
```

Новые образцы появятся в `sport-platform/target/s09-samples/`. Растровая проверка в тесте подтверждает, что текст расположен поверх фона; PDFBox также проверяет размеры и число страниц, кириллицу и наличие изображения фона.

После ревью 1 фон грамоты задаётся один раз в CSS и используется повторно всеми страницами. Перф-тест дополнительно загружает через API JPEG 2480×3508 с шумом (1 868 291 байт), формирует 200 грамот и проверяет 200 страниц, время ≤20 с, размер PDF ≤3 размеров фона и один общий XObject изображения. Большой тестовый PDF не хранится в Git.
