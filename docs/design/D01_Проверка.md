Проверка merge-tree с актуальным main — без конфликтов, в том числе LoginPage.tsx и OrganizerHeatsPage.tsx.

1. На 375 px th, годы, время и номера не переносятся; фамилии — только между словами. Ячейки 6×4 px, номер 18 px. Таблица при необходимости прокручивается внутри себя (`display:block; overflow-x:auto`) без новых обёрток и без горизонтального скролла документа. В e2e проверяются текстовые Range, а не bounding box td: каждая ячейка времени/года имеет одну текстовую строку.
2. Border-top карточки входа перенесён после border shorthand; 4 px видимы в обоих viewport. После решения владельца линейка использует новый graphite primary.

Тест подтверждает, что весь текущий блок, включая 8 дорожек и действие, помещается над нижней навигацией без scrollY. [Отдельный снимок 1366×768](screenshots/D01-live-1366-eight-lanes.png).
4. На 375 px первый столбец судьи sticky/left:0 с непрозрачным surface-фоном и z-index:1; после горизонтального скролла его x не меняется (с допуском 1 px на округление границы).
5. Print: все surface/soft-фоны белые, все status-foreground и семантические foreground чёрные. Status-soft белые (не чёрные), чтобы бейджи сохраняли чёрный текст на белом фоне. QA06-15 проверяет токены и карточку в print из тёмной темы; автоматические тёмные CSS-маркеры действуют только в screen media.

### Решение владельца по цветам и теме

- Primary `#334654`, hover `#1f2933`, soft `#e9eff4`; с белым текстом **9.79:1 / 14.76:1**. Холодный графит отличается от text `#182126`; ночной вариант нейтральный светлый с тёмным on-primary, без красного.
- Красный — только danger/DSQ/ошибки и LIVE. Нейтральные цвета штрихов SVG/PWA-иконок; геометрия знака не менялась. Дорожки 4–5: полоса 4 px text + weight 700, без заливки; остальные без видимой полосы. Селекты кабинета тоже нейтральные.
- «Печать», «Открыть заплыв», сегменты результатов, повтор загрузки, второстепенные переходы — ghost. На публичном экране не больше одного primary.
- CORRECTED — warning/warning-soft; DSQ — danger, DNS/DNF — muted. У кнопок судьи изменены только классы; у публичных статусов — только классы td. [Сравнение CORRECTED](screenshots/D01-judge-detail-comparison.png) использует одинаковую тестовую MSW-фикстуру до/после.
- Disabled primary: border-strong / text-muted, opacity 1. Это неактивные элементы, исключённые из контраста AA активного текста.
- Live/results всегда тёмные: `fl-live-page` / `fl-results-page` добавлены к уже существующим элементам, CSS `:root:has(...)` меняет только токены. Пустые результаты тоже тёмные. Переключатель/localStorage **не делать** в D01; раздел D02 добавлен в концепцию.
