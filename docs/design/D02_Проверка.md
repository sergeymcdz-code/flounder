QA06-07/results: третий пункт «Опубликовать результаты вида» disabled;
ожидание enabled падает до отметки expected failure. Сбой уже описан
в [D01 — проверка](D01_Проверка.md), публикация D02 не изменялась.

Полный demo после этого rebase не повторялся: текущий запрос требует
frontend-проверки и e2e 375. Предыдущий реальный demo 13.10 выполнил
все семь шагов; три soft errors были только в шаге 4 (QA05-01 checkbox
circleSeedTopHeats и два QA05-03 пустого draft print). Шаги 5/7 тогда строго
проверяли data-theme=dark и прошли, опубликованные PDF сформированы.

В backend сохранился известный shutdown warning Surefire после System.exit(0);
exit 0 и XML-отчёты без ошибок. Локальный MSW-судья может показывать прежнюю
ошибку определения следующего заплыва из-за доступа к событию; та же фикстура
снята на main, права/логика D02 не менялись. Физические Android/iOS и
VoiceOver недоступны; проверены Chromium 375, role=table, фокус и ввод.
Широкий селектор disabled из D01 оставлен; новые локальные правила D02
ему не противоречат. API-клиенты, RBAC, данные и backend не менялись.

Журналы backend находятся в `work/d02-rebase/`, frontend/e2e/axe/исходные
снимки — в `frontend/work/d02-rebase/`; они не коммитятся.

## Как проверить вручную

1. `cd sport-platform/frontend && npm ci`; `VITE_API_MOCK=true npm run dev`.
   Открыть `/e/demo` со светлой системой и пустым flounder.theme:
   страница светлая; `/e/demo/live` и `/e/demo/results` тёмные.
2. Нажать «Светлая» на табло: body и таблица светлые. Перейти в результаты,
   перезагрузить: выбор сохраняется. Повторить для «Тёмная», проверить
   фокус кнопки, системную тему без выбора и синхронизацию вкладок.
3. Открыть `/login`, затем вернуться к событию: форма светлая,
   публичный выбор восстановлен. При блокировке localStorage кнопка
   работает до reload.
4. В панели судьи на 375 прокрутить таблицу: дорожка и фамилия закреплены.
   Сфокусировать время: поле целиком видно, 24 px / 56 px, ввод цифр и
   Enter/Tab/Esc работают. После сохранения уведомления доступны скринридеру.
5. Проверить Заявки/Программу, `/admin/*`, регистрацию и Мои заявки
   на 1366/375. На публичном протоколе Tab фокусирует таблицу,
   стрелки прокручивают её; годы/время/слова не рвутся.
6. Проверить сохранность «Скачать PDF» M03 и ghost «Печать» в двух темах.
   Распечатать опубликованный протокол из dark: белый A4/15 мм,
   навигация/переключатель скрыты, заголовки повторяются.
7. Выполнить npm test/build/lint и test:qa06; для полного backend/demo
   использовать AGENTS.md и e2e/QA05-README.md, учитывая исходные сбои выше.
