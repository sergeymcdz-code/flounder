# ADR 2026-10-13: порядок слияния PR с миграциями V031–V034

## Контекст
Задания закрепили номера: M04 — V031, M05 — V032, M06 — V033, M07 — V034. Flyway на стенде без `outOfOrder`: если V034 применится раньше V032, деплой с V032 упадёт на validate.

## Решение
Сливать и деплоить PR с миграциями строго в порядке номеров: M04 (#38) → M05 (#41) → M06 → M07 (#40). PR без миграций (M03, M08, QA07, QA04 r2, M01-followups) — в любой момент. `spring.flyway.out-of-order` не включаем; если порядок сломается по срочности — включить осознанно отдельным PR с записью здесь.

## Последствия
M07 ждёт M04/M05/M06 даже при готовности раньше; M08 зависит от M07 только тестом (`add column if not exists`).
