# T07 · Поток C · Публичные страницы, печатные протоколы, форма заявки, PWA (frontend)

Прочитай `AGENTS.md`, `docs/02_ТЗ_демо.md` §5.4 (публичная форма), §5.7, §6.3–6.5. Ветка `feat/T07-public-pwa` от `main` после слияния T04 (общие компоненты). Срок: 14.10. Бэкенд T06 может быть не слит — моки MSW по контракту.

## Цель
Родитель/участник/зритель с телефона видит расписание, «сейчас идёт заплыв №N», свои заплывы и результаты; организатор печатает стартовый и итоговый протоколы на A4; сайт устанавливается как приложение.

## Что сделать
1. Маршруты `/e/:slug`, `/e/:slug/start-list`, `/e/:slug/schedule`, `/e/:slug/live`, `/e/:slug/results`, `/e/:slug/register`; существующие `/events/:eventCode` → редирект на `/e/:slug`. Публичный layout: шапка с названием соревнования и датой, нижняя навигация на телефоне (Расписание · Live · Результаты · Найти себя), без боковой панели.
2. **Карточка** `/e/:slug`: даты, площадка, сессии, кнопки разделов, «Подать заявку» (если `registrationOpen`).
3. **Стартовый протокол** `/e/:slug/start-list` (§6.4): группировка сессия → вид → заплыв; пустые дорожки показывать прочерком; снятые — зачёркнуты; кнопка «Печать» вызывает `window.print()`; при `?print=1` страница сразу открывает диалог печати после загрузки. CSS `@media print`: A4, поля 15 мм, шрифт 10–11 pt, шапка на каждой странице (`position: fixed` + отступ), `break-inside: avoid` для заплыва, скрыть навигацию. Проверить в Chrome «Сохранить как PDF» — страницы не обрезаны, таблицы не рвутся посередине заплыва.
4. **Расписание** `/e/:slug/schedule`: лента по времени с группировкой по сессии; прошедшие — приглушены; текущий — выделен.
5. **Live** `/e/:slug/live`: крупно «Вид № 3 · 50 м в/с, девушки · Заплыв 2 из 5», время старта, таблица дорожек текущего заплыва, «Далее» — 3 заплыва; автообновление каждые 15 с (`setInterval`, пауза при скрытой вкладке); блок «Найти себя»: поле фамилии → карточка спортсмена: заплывы (вид, заплыв, дорожка, время старта) и результаты (время, место, место в группе).
6. **Результаты** `/e/:slug/results`: по видам — переключатель «Абсолют / По группам», таблица `Место | Фамилия Имя | Год | Клуб | Результат`, DNS/DNF/DSQ внизу; печатная форма как у стартового протокола (`?print=1`).
6a. **Лист награждения**: `/e/:slug/results?awards=1` — по видам и группам только места 1–3 (`Место | Фамилия Имя | Год | Клуб | Результат`), `page-break` по виду. **QR-плакат**: `/e/:slug/poster` — A4: название, даты, площадка, крупный QR на `/e/:slug/live`, подпись «Расписание, «сейчас на старте» и результаты — на телефоне». На карточке `/e/:slug` — ссылка «Положение (PDF)», если `regulationUrl` не null.
7. **Форма заявки** `/e/:slug/register` (мобильная, §6.3): если не авторизован — экран «Войдите или зарегистрируйтесь» с переходом на существующие страницы и возвратом (`?next=`); форма: фамилия, имя, отчество, дата рождения (нативный date input), пол, клуб/город; список видов, отфильтрованный по полу и году (неподходящие скрыты, с переключателем «показать все» и пометкой), у выбранных — поле заявочного времени с маской `мм:сс.сс` и подсказкой «можно оставить пустым»; чекбокс согласия на обработку персональных данных (текст-заглушка «Я даю согласие … (демо)»); отправка → экран «Заявка отправлена» со списком видов и статусом; ошибки бэкенда по видам показывать под соответствующими пунктами.
8. **PWA**: `vite-plugin-pwa` с `registerType: 'autoUpdate'`, manifest (name «Flounder», short_name «Flounder», lang ru, theme_color `#0b5b7b`, background `#ffffff`, display standalone, start_url `/`, иконки 192/512 — сгенерировать простую: буква F на синем круге, SVG → PNG), workbox: `networkFirst` для `/api/v1/public/**`, `cacheFirst` для статики, офлайн-страница «Нет связи, показаны последние данные». В `index.html` — `<meta name="theme-color">`, apple-touch-icon.
9. Доступность и мобильность: контраст ≥ 4.5:1, целевые зоны ≥ 44 px, работа на 375 px без горизонтального скролла, `lang="ru"`.

## Критерии приёмки
- Lighthouse (mobile) на `/e/:slug/live`: PWA installable, Performance ≥ 80, Accessibility ≥ 90.
- PDF стартового протокола на наборе из 6 заплывов — 1–2 страницы, без обрезаний (приложить PDF к PR).
- Скриншоты телефона (375×812) всех публичных страниц в PR.
- `npm run build` и `npm run lint` чистые.
