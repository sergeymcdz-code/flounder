# D02. Переключатель темы, доводка визуального стиля после D01

Прочитай `AGENTS.md`, `docs/design/D01_Концепция.md`, `docs/decisions/2026-10-13-d01-cveta-i-tema.md`, `docs/reviews/D01-review-1.md` (раздел «Желательные»). Ветка `feat/D02-theme-toggle` от актуального `main` **после слияния D01 (#30)**; если D01 ещё не слит — от `feat/D01-visual-style` с последующим ребейзом. Один PR. В отличие от D01 здесь разрешено менять разметку компонентов (без изменения логики данных и текстов API).

## Что сделать
1. Переключатель темы: компонент `ThemeToggle` (кнопка «Светлая/Тёмная», иконка, aria-label) в шапке публичных страниц; состояние в `localStorage` (`flounder.theme`), атрибут `data-theme` на `<html>`, без мигания при загрузке (inline-скрипт в `index.html`); по умолчанию `/live` и `/results` — тёмная, остальные публичные — светлая; `prefers-color-scheme` учитывать при отсутствии сохранённого выбора. Печать всегда светлая.
2. Панель судьи на 375: первый столбец (дорожка/фамилия) `position: sticky`; поля времени ≥ 44 px высотой; клавиатура телефона числовая (`inputmode="decimal"`, разметку поля можно менять).
3. Шрифты: субсет WOFF2 (кириллица + латиница + цифры), суммарно ≤ 120 КБ; `font-display: swap`.
4. Экраны, не затронутые D01 (кабинет организатора «Заявки», «Программа», админка `/admin/*`, формы входа/регистрации, «Мои заявки»): привести к токенам D01 — кнопки, таблицы, бейджи, пустые состояния; без новых компонентов.
5. Доступность: фокус-кольца на всех интерактивных элементах, `aria-live` для уведомлений панели судьи, контраст AA по таблице D01.
6. Скриншоты до/после (≤ 15 файлов, ≤ 3 МБ) в `docs/design/screenshots/D02-*`; обновить `docs/design/D01_Концепция.md` разделом «D02».

## Не делать
Не менять логику, API-клиенты, тексты интерфейса; не трогать e2e-локаторы без обновления тестов.

## Проверка
`cd sport-platform/frontend && npm run build && npm run lint && npm test`, `npm run test:qa06`, `npm run test:demo` против локального backend (шаги 5 и 7 — тёмная тема на табло). В PR: скриншоты, что не сделано.
