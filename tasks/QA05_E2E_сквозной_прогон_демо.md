# QA05. Сквозной E2E-прогон сценария демо (frontend + backend, Playwright)

Правила — `tasks/QA00_Общие_правила_тестирования.md`. Ветка `qa/QA05-e2e-demo`.

Задача: автоматизировать 7 шагов `docs/demo-script.md` как Playwright-тесты в `sport-platform/frontend/e2e/` (добавь `@playwright/test` dev-зависимостью, `npm run e2e`; тесты против реального бэкенда на localhost с сидом `scripts/demo`; если Docker/бэкенд недоступны — против MSW-моков с пометкой в отчёте, какие шаги прошли только на моках).

Шаги и что ассертить:
1. Обзор: `/e/{slug}` без входа — название, площадка «25 м, 8 дорожек», 2 сессии, 4 вида; кабинет `org@` — пресет «детские 2 года», `circleSeedTopHeats` выключен; QR и публичная ссылка в UI организатора.
2. Импорт: шаблон скачивается; `set-M-with-errors.xlsx` → 203/200/3 с нужными строками и текстами; затем `set-M.xlsx` → 200 заявок в списке, не 400.
3. Родитель, viewport 375×812: вход `parent@`, `/e/{slug}/register`, Демов Тимофей 18.04.2014, 50 и 100 в/с, времена `00:47.20` и `01:49.50`; у организатора 202 заявки, две `SUBMITTED`; подтверждение; секретарь `sec@` отмечает оплату.
4. Посев по событию: ≤5 с, 0 ERROR; центральные дорожки 4,5,3,6,2,7,1,8; `scheduledAt` 10:00/15:00; `estimatedEndsAt`; стартовый протокол → `page.pdf({format:'A4'})` — файл создан, ни один заплыв не разорван (проверь по тексту PDF или по CSS `break-inside`); публикация; `/e/{slug}/start-list` без входа.
5. Live: секретарь ставит первый заплыв текущим; `/e/{slug}/live` показывает «Сейчас» и 3 следующих; «Найти себя» → Демов, оба старта; автообновление ≤15 с (меняем live и ждём без reload); manifest и service worker отдаются (PWA).
6. Снятие F-100-FREE из позднего заплыва → `WITHDRAWN`, пустая дорожка, соседи не двигались, пересчёт расписания, WARNING валидатора.
7. Результаты: ввод по заплыву (время, DNS, DSQ), «Сохранить и пересчитать», публикация, `/e/{slug}/results` — места, равные времена 1,1,3; исправление → `CORRECTED`; итоговый протокол в PDF.

Дополнительно: консоль браузера без ошибок на всех страницах (собирай `page.on('console')`/`pageerror`), нет запросов с 4xx/5xx кроме ожидаемых, каждая страница — скриншот в `docs/qa/screenshots/QA05-*.png` (desktop 1366 и mobile 375). Отчёт `docs/qa/QA05-e2e-demo.md` со списком дефектов по шагам.
