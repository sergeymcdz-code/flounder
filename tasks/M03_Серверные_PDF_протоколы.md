# M03. Серверная генерация PDF: стартовый и итоговый протоколы

Прочитай `AGENTS.md`, `docs/02_ТЗ_демо.md` §2 US-4/US-6, §6.4, `docs/03_ТЗ_MVP_50_соревнований.md` §3.5. Ветка `feat/M03-server-pdf` от актуального `main`. Новый модуль `documents` (`com.acme.sportplatform.documents`), один PR.

## Зачем
Сейчас протокол печатается только через «Печать → PDF» в браузере: зависит от браузера, нельзя отправить файл, нельзя приложить к письму. Нужен PDF с сервера, одинаковый у всех.

## Что сделать
1. Зависимость `com.openhtmltopdf:openhtmltopdf-pdfbox` (+ `openhtmltopdf-slf4j`); кириллический шрифт (например, PT Sans или Noto Sans, лицензия OFL) положить в `src/main/resources/fonts/` и зарегистрировать; без него кириллица в PDF не отобразится — это первый тест.
2. Шаблоны Thymeleaf (`spring-boot-starter-thymeleaf`) в `resources/templates/documents/`: `start-list.html` (шапка: название, площадка, дата, организация; по каждому виду — таблица заплывов: № заплыва, дорожка, фамилия имя, год рождения, клуб, заявочное время, время старта; `page-break-inside: avoid` на заплыв; колонтитул с номером страницы и временем генерации), `results.html` (итоговый протокол: по виду — абсолют и по возрастным группам, место, фамилия имя, год, клуб, результат, статус DNS/DNF/DSQ, `CORRECTED` пометка), A4 портрет, поля 15 мм, `@page`.
3. Данные — через публичные `*Lookup` модулей `competition`/`scheduling`/`results`/`organizations` (не через чужие репозитории), по аналогии с `publication`. Если нужного Lookup нет — добавить минимальный метод в корне соответствующего модуля и перечислить в PR.
4. Эндпоинты: `GET /api/v1/events/{eventId}/documents/start-list.pdf` и `GET /api/v1/events/{eventId}/documents/results.pdf` (организатор/оператор — `assertCanManage`; `Content-Disposition: attachment; filename*=UTF-8''…`); публичные `GET /api/v1/public/events/{slug}/start-list.pdf` и `/results.pdf` — только опубликованные данные (те же правила видимости, что у публичного API T06), кеш 60 с по slug.
5. Фронт: кнопки «Скачать PDF» на странице заплывов организатора, на странице результатов организатора и на публичных `/e/{slug}/start-list` и `/results` (рядом с «Печать»). Без изменения остальной вёрстки.
6. Тесты: генерация на наборе M (фикстура `docs/scripts/demo/out/set-M.json` или сид в тесте) — PDF валиден (PDFBox открывает), содержит кириллицу (извлечь текст и найти фамилию), ≥1 страницы, время генерации ≤3 с на 200 заявок; доступ чужого организатора → 403; неопубликованные заплывы не попадают в публичный PDF.

## Не делать
Грамоты, листы награждения, XLSX-экспорт, Lenex — следующие задачи. Не менять алгоритм ранжирования.

## Проверка
`mvn -q test`, `npm run build && npm run lint`. В PR: приложи сгенерированный PDF (или скриншот страницы), опиши шрифт и лицензию, что не сделано.
